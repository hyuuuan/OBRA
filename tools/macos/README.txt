O.B.R.A. macOS playtest

Double-click "Play OBRA.command" to start the game.
Double-click "Collect playtest data.command" after quitting the game to copy
anonymous telemetry and profile.json into playtest-data/<participant-code>.

The game stores telemetry here:
  ~/Library/Application Support/Godot/app_userdata/O.B.R.A/telemetry

Keep the game, backend, model, shared, and .venv folders together.
